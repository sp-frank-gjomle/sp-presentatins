# Byggteknisk – Automation workshop: forberedelser

For at du skal få mest mulig ut av dagen, og kunne gjøre hands-on-oppgaven til slutt,
må dette være på plass **før** workshopen.

> **Søk i god tid.** Tilganger i BAT må godkjennes og kan ta flere dager.

## Sjekkliste

- [ ] **VS Code installert på din lokale PC**
  - Start VS Code og sjekk at den åpner seg.
- [ ] **Tilgang til nødvendige extensions i VS Code**
  - Søk i BAT om: **Microsoft VS Code Extensions GPO Appdrift PC-tilgang SPHF**
  - Sjekk: Åpne Extensions-visningen i VS Code og se at du kan installere f.eks. Ansible- og PowerShell-extensions.
- [ ] **Tilgang til GitLab** – <https://gitlab.sikt.sykehuspartner.no>
  - Sjekk: Logg inn og se at du kommer inn.
- [ ] **Tilgang til ProGet** – <https://pb.sykehuspartner.no/>
  - Sjekk: Åpne siden og logg inn.
- [ ] **Tilgang til Ansible Days i GitHub**
  - Søk i BAT om: **GitHub medlem team helse-sorost ansible-days-cloud-members SPHF**

## Hvorfor trenger du dette?

| Forutsetning     | Brukes til                                                                 |
| ---------------- | -------------------------------------------------------------------------- |
| VS Code          | Editoren vi bruker hele dagen – kode, terminal og Git i samme vindu        |
| Extensions       | Godkjente tillegg for Ansible, PowerShell, Copilot m.m.                    |
| GitLab           | Klone demo-repoet, lage branch og kjøre pipeline i hands-on                |
| ProGet           | Intern lagerplass for container-images og installasjonsfiler (assets)      |
| Ansible Days     | Læringsmateriell om Ansible – til videre læring etter workshopen           |

Ta kontakt med kursholder hvis noe ikke kommer på plass før workshopen.
